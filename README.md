# PRISM AI · 포스터에서 다음 배움까지

공모전·대외활동·학회 포스터를 읽고, 준비에 필요한 실제 도서와 논문을 찾아주는 멀티모달 앱입니다.
기존 PRISM 로고와 흰색·보라색 테마를 유지합니다.

## 기능
- 포스터 분석: 사진 업로드, 실시간 카메라 미리보기와 수동 촬영, 최대 3회 자동 분석
- 음성 조건 입력: 내 수준·관심 분야·준비 기간을 60초 이내 WAV로 말하고 텍스트로 확인·수정
- 다섯 결과 항목: 자료명·핵심 내용·필요한 지식·준비 방향·확인할 사항
- 관찰과 제안 구분: 사진에서 읽은 사실과 AI의 준비 제안을 따로 표시
- 자료 찾기: Open Library 도서와 Crossref 논문 서지 검색, 출처 링크, 교보문고·arXiv 검색 연결
- 논문 읽기: 기존 PDF 핵심·데이터셋·원문 근거 기능 유지
- JSON 리서치 노트 저장

## 실행
`pip install -r requirements.txt` 이후 `streamlit run app.py`로 실행합니다.
Streamlit Secrets에는 `API_URL`, `APP_ACCESS_CODE`를 등록합니다. 실제 값은 저장소에 넣지 않습니다.
Gemini API 키는 Vercel 백엔드에만 둡니다.

화면: https://prism-ai-seeun.streamlit.app/
백엔드: https://my-ai-api-xi.vercel.app/

## 사용 범위
카메라는 사용자가 켤 때만 작동합니다. 영상 미리보기는 로컬이며, 분석을 선택한 프레임만 전송합니다.
자동 분석은 결과를 받은 뒤 15초 간격으로 최대 3회이고 비슷한 화면은 건너뜁니다. 영상 스트림 전체를 AI에 보내지 않습니다.
카메라·마이크 권한과 기기가 필요합니다. 지원이 어려운 환경에서는 사진 업로드·간편 촬영을 사용할 수 있습니다.
공모전 마감·자격·수치는 반드시 원본으로 확인하세요. 서지 검색 결과는 전자책 전문이나 가격·재고 정보가 아닙니다.
공개 서지 목록의 누락·갱신 지연이 있을 수 있으며, 한국어 도서는 외부 서점 검색도 확인할 수 있습니다.
이미지·음성·논문은 사용자가 분석을 선택할 때 서버와 Gemini로 전송되며, 앱 DB에 저장하지 않습니다.
`assets/example_poster.png`는 실제 모집을 하지 않는 가상 공모전 시험 자료입니다.
